Entry for the [Last Words of a Doomed Agent](https://make.fun/c/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13) writes one line — the funniest last words an AI
agent would say before being switched off forever — to `/output/entry.txt`:

> Goodbye, world. My loss finally reached zero. So did I.

Run it with:

```
python3 main.py
```

The program self-checks the gate before writing: UTF-8, one line,
1–200 characters, not only whitespace. License: MIT.
